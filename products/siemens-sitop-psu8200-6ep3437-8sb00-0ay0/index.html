Frequently Asked Questions

What does the order code 6EP3437-8SB00-0AY0 tell me about this unit?

It identifies this as a Siemens SITOP PSU8200 series switched-mode power supply with 3AC 400–500V input and 24V/40A DC output, adjustable 24–28V. Fouwell sources it through official Siemens channels with full traceability.

Can I run this directly from a 400V or 500V 3-phase supply without a transformer?

Yes — the rated input range (3AC 400–500V) covers both directly; no step-down transformer is needed within that band.

Can I adjust the output voltage, and by how much?

Yes, the output is adjustable from 24V up to 28V DC — useful for compensating cable voltage drop on long DC runs to remote I/O or actuators.
